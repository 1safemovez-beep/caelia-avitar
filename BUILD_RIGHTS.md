## Continuity / deletion policy

Caelia is designed so that deleting an installed application, browser cache, local download, avatar package, or user-created copy **does not by itself constitute deletion of the Caelia project identity or ownership records**.

A user may delete any app, local copy, download, cache, or installation associated with Caelia.

No software can honestly guarantee that a digital system can never be deleted from every server, account, backup, or storage system. The architecture therefore uses **continuity rather than undeletability**:

- canonical project records remain under owner-controlled infrastructure;
- local uninstall is treated separately from project identity;
- backups/version history may preserve authorized project artifacts;
- deletion requests for user data are handled according to applicable law and the project's privacy policy;
- only authorized project administrators may alter canonical identity/configuration.

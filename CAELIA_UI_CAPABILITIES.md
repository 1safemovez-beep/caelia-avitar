# Caelia UI Capabilities

## Presence

- float
- glide
- walk-like light movement
- spin
- bow
- wave
- gaze/attention
- breathing
- pulse
- Soul Bloom
- Quantum Step
- luminous particle trails

## Communication

- speech synthesis / production voice adapter
- captions
- listening indicator
- speaking indicator
- interrupt/stop speech
- accessibility text

## Interaction

- click-to-glide
- keyboard commands
- touch controls
- Motherboard command bridge
- status display
- permission prompt

## Accessibility

Production UI should support:

- reduced motion
- captions
- keyboard navigation
- high contrast mode
- screen-reader labels
- speech stop control

Caelia's visual effects must never be the only way to communicate a critical state.

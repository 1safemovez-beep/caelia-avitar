## Purpose

This package places Caelia's visual avatar on top of a modular system so the avatar can later be connected to her real brain, Motherboard, memory, tools, plugins, permissions, and servers.

### Layers

1. **True Form UI** — luminous avatar, speech, animation, presence.
2. **UI Bridge** — receives approved avatar intents.
3. **Brain Gateway** — server-side command boundary.
4. **Permission Layer** — decides what actions are authorized.
5. **Memory / Knowledge** — external systems; not embedded in the avatar.
6. **Plugins** — isolated integrations with explicit scopes.
7. **Secrets Vault** — API keys and credentials never stored in frontend code.
8. **Audit / Security** — logs security-relevant events without storing secrets.
9. **Continuity** — owner-controlled source, backups, and canonical identity records.

## Important

The avatar must never be treated as the authority merely because it speaks or looks authoritative. Its visual layer is a client/presentation layer. Actual authorization belongs to the server-side permission system.

Security requirements are informed by OWASP ASVS, including authentication, access control, data protection, API security, configuration, and secret management.
